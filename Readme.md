
# 🏎️ Dashboard Gamificado - Race Track (Power BI)

Este repositório contém o código, a modelagem de dados e a apresentação de um projeto de **Business Intelligence** desenvolvido em Power BI, focado em visualização dinâmica e gamificação.

## 🚀 Sobre o Projeto
O objetivo principal deste projeto foi criar um relatório interativo e visualmente imersivo, saindo dos padrões tradicionais corporativos e aplicando conceitos de gamificação com pistas de corrida, avatares em movimento e indicadores de desempenho em tempo real.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Power BI**: Desenvolvimento do dashboard, relatórios e design visual.
* **DAX**: Criação de medidas calculadas avançadas para lógica de negócio e métricas.
* **Modelagem de Dados**: Estruturação em esquema estrela (Star Schema).
* **SVG & HTML Content**: Elementos visuais personalizados para a experiência gamificada.
* **Git & GitHub**: Controlo de versões e publicação do portefólio.

---

## 📊 Principais Funcionalidades
* **Pista de Corrida Interativa**: Indicadores de progresso visuais baseados no desempenho.
* **Métricas Dinâmicas**: Cálculos em tempo real com DAX para acompanhar KPIs essenciais.
* **Design Otimizado**: Interface limpa, moderna e responsiva focada na experiência do utilizador.
